5 Batasi CORS Origin High ▸

server.js — app.use(cors()) dan Socket.io cors: { origin: '*' }. Semua origin diizinkan tanpa filter.

Jika TIDAK Diperbaiki
  • Situs mana saja bisa akses API endpoints
  • Admin session bisa di-hijack dari domain lain
  • Socket.io events bisa di-intercept
  • CSRF ke /api/login dimungkinkan
JIKA Diperbaiki
  • Hanya dashboard domain yang bisa akses
  • Admin session aman dari cross-origin attacks
  • Socket.io hanya terima koneksi trusted
Step-by-step
1
Define allowed origins — ALLOWED_ORIGINS dari env var, comma-separated. Default: http://localhost:3000.
2
Apply CORS whitelist — Ganti cors() dengan cors({ origin: function(origin, callback) {...} }) yang cek origin terhadap whitelist.
3
Apply ke Socket.io — cors: { origin: ALLOWED_ORIGINS } di Server constructor.
